# silversmith
Collection of skills and agentic config

## Skills

Each skill is a folder under [`skills/`](skills/) following the
[Agent Skills](https://agentskills.io) open standard (`SKILL.md` +
optional `references/`), usable by any tool that supports the standard.

| Skill | Description |
|---|---|
| [npm-publish](skills/npm-publish/SKILL.md) | Secure npm package publishing — trusted publishing (OIDC), automatic provenance, staged publish with 2FA approval, dist-tag promotion, pre-publish gates. |
